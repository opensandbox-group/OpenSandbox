## 状态说明

| 符号 | 含义 |
|------|------|
| ✅ | 已实现并联调路径 |
| 🔶 | UI 已有，依赖集群能力或仅 Admin/租户部分可用 |
| 📋 | 占位说明，需后续 BFF+K8s RBAC |

## 已知限制

1. **Pool API** 不按租户隔离（与 `tenants-configmap.yaml` 一致）。
2. **K8s 平台页** 需独立 ServiceAccount + BFF 扩展（P3）。
3. **快照 / 诊断** 在 Admin 会话下需额外产品策略（当前 BFF 以租户 Key 代发为主）。
