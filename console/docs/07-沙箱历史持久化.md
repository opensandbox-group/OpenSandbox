# 沙箱申请历史（单表 `sandbox_lifecycle_history`）

与 OpenSandbox Server **共用 PostgreSQL**（如 `opensandbox`）。一张表 **`sandbox_lifecycle_history`**：

| 写入方 | 时机 | 字段 |
|--------|------|------|
| **Server**（`[store.lifecycle_audit] enabled=true`） | Lifecycle API create/delete 成功后异步 | 租户、镜像、状态、创建/删除时间、limits 摘要等 |
| **Console BFF** | Console 创建/列表/对账/删除 | 同上 + **`create_request`**、`source=console*` 等 |

SDK/脚本直连 Server 也会由 Server 写入；Console 打开历史页 **不必**再依赖全量 Lifecycle 对账（建议 `BFF_HISTORY_RECONCILE_ON_READ=false`）。

## 启用

**Server**（`sandbox.toml` / Helm `configToml`）：

```toml
[store]
type = "postgresql"

[store.lifecycle_audit]
enabled = true
```

**BFF**：

| 变量 | 说明 |
|------|------|
| `BFF_HISTORY_ENABLED` | `true` |
| `BFF_HISTORY_DATABASE_URL` | 与 Server 同库 |
| `BFF_HISTORY_RECONCILE_ON_READ` | 默认 `true`；Server 审计开启后建议 `false` |

BFF 启动时 `CREATE TABLE IF NOT EXISTS sandbox_lifecycle_history`（仅新表，不再读取或导入 `console_sandbox_history` 等旧表）。

## 写入与统计

- **Server 审计**：凡 create/delete API → 行必记（与 Console 是否打开无关）。
- **BFF**：经 Console 的操作在同一行上 **补** `create_request` 等；可选 reconcile 刷新仍在跑的沙箱状态。
- **历史 / 用量 / 镜像统计**：均 `SELECT sandbox_lifecycle_history`（单表，无 merge）。

## API

见 [02-BFF配置与Secret.md](./02-BFF配置与Secret.md) 与 `/api/history/*`。

## 权限

- 同库用户需 `SELECT, INSERT, UPDATE` on `sandbox_lifecycle_history`；读快照数需 `SELECT` on `snapshots`。
