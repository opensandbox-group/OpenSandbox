# OpenSandbox Manifests

Deployment artifacts for OpenSandbox — Helm charts live here as a stable,
top-level location, separate from the Kubernetes operator source under
[`kubernetes/`](../kubernetes/).

## Layout

```
manifests/
└── charts/
    ├── opensandbox/             # Umbrella chart — installs the full stack
    ├── opensandbox-controller/  # Controller (CRDs + operators)
    ├── opensandbox-server/      # OpenSandbox server
    └── opensandbox-node-agent/  # Node agent (DaemonSet)
```

## Quick Start

### Install the full stack (umbrella chart)

```bash
helm dependency build manifests/charts/opensandbox
helm install opensandbox manifests/charts/opensandbox \
  --namespace opensandbox-system \
  --create-namespace
```

### Install an individual component

```bash
helm install opensandbox-controller manifests/charts/opensandbox-controller \
  --namespace opensandbox-system \
  --create-namespace
```

### Verify

```bash
kubectl get pods -n opensandbox-system
helm list -n opensandbox-system
```
