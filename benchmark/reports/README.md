# Benchmark Reports Archive

This directory stores commit- and tag-stamped milestone and pre-release benchmark reports generated by `opensandbox-bench`.

## Directory Convention

Each archived run lives under `<tag-or-date>-<short-commit>/` and contains:

- `report.json`: Structured `schema_version: 2` JSON report stamped with exact `OpenSandbox` and `fast-sandbox` git `commit` SHAs and `tag`s.
- `summary.md`: Human-readable Markdown summary including latency tables, load profiles, leak audit results, and P99 trace bottleneck attribution.
- `traces/`: Sampled OTel span trees (`<trace_id>.json`) for offline waterfall inspection via `opensandbox-bench trace <bundle-dir>`.

## Comparing Reports

```bash
opensandbox-bench compare \
  benchmark/reports/<baseline>/report.json \
  benchmark/reports/<candidate>/report.json \
  --fail-on-regression
```
