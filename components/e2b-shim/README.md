# OpenSandbox E2B Shim (Scaffold)

Optional component proposed by [OSEP-0027](https://github.com/opensandbox-group/OpenSandbox/blob/main/oseps/0027-optional-e2b-compatibility.md). Scaffold only: it serves a liveness check. No E2B operation is implemented or tested.
