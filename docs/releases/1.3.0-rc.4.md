Fourth release candidate on the `1.3.0` feature line, cut from `release-1.3.0-rc.3` (2026-11-23). Baseline for every section is `release-1.3.0-rc.3`; rc users on that tag should upgrade. rc releases publish images but hold packages — SDK/CLI artifacts ship at the `1.3.0` stable bump.

## Highlights

- **Scheduling & create hot-path performance tuning:** server creates move to event-loop `grpc.aio` ([#3150](https://github.com/opensandbox-group/OpenSandbox/pull/3150)) and a shared `SandboxPool` informer ([#3120](https://github.com/opensandbox-group/OpenSandbox/pull/3120)), while the Kubernetes controller adds opt-in Pod/Job informer cache label selectors ([#3158](https://github.com/opensandbox-group/OpenSandbox/pull/3158)). On Fast Sandbox, `ResourceAware` memory admission excludes reclaimable page cache ([fast-sandbox#263](https://github.com/opensandbox-group/fast-sandbox/pull/263)), OCI templates enable `virtio-balloon` free-page reporting by default ([fast-sandbox#252](https://github.com/opensandbox-group/fast-sandbox/pull/252)), `FAST_SANDBOX_NETWORK_CIDR` unlocks >126 slots per Fastlet ([fast-sandbox#284](https://github.com/opensandbox-group/fast-sandbox/pull/284)), and per-sandbox startup trims latency across `overlaybd-ublkd` hybrid upper creation ([fast-sandbox#286](https://github.com/opensandbox-group/fast-sandbox/pull/286)), pre-warmed guest routes/NAT ([fast-sandbox#285](https://github.com/opensandbox-group/fast-sandbox/pull/285)), single-image OCI `RootfsOnly` snapshots ([fast-sandbox#258](https://github.com/opensandbox-group/fast-sandbox/pull/258)) ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165)), batched `O(1)` egress MITM/DNS nftables updates ([#3151](https://github.com/opensandbox-group/OpenSandbox/pull/3151)), and reduced Actions v2 `fsync`/owner reads ([#3152](https://github.com/opensandbox-group/OpenSandbox/pull/3152))
- **Stateless HMAC `execd` authentication, `/internal/init` hardening & local `exec` actions:** Kubernetes sandboxes can derive per-sandbox `X-EXECD-ACCESS-TOKEN` credentials from versioned HMAC master keys (`[execd].auth_signing_key_file`) so plaintext tokens never land in Pod specs or etcd ([#3080](https://github.com/opensandbox-group/OpenSandbox/pull/3080)), paired with opt-in `EXECD_INIT_AUTH` and a 1 MiB body cap on `POST /internal/init` ([#3103](https://github.com/opensandbox-group/OpenSandbox/pull/3103)), an ingress gateway `403` block on `:44772/internal/init` ([#3111](https://github.com/opensandbox-group/OpenSandbox/pull/3111)), cross-origin redirect token stripping across SDKs ([#3101](https://github.com/opensandbox-group/OpenSandbox/pull/3101)), and Fastlet-local `exec` `ActionHandler` support ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#269](https://github.com/opensandbox-group/fast-sandbox/pull/269))
- **Additive Credential Vault bindings, audit logs & egress drop telemetry:** Credential Vault bindings with disjoint static headers and substitution surfaces now compose deterministically across wildcard and exact host scopes alongside sanitized vault/MITM `INFO` audit logs ([#3169](https://github.com/opensandbox-group/OpenSandbox/pull/3169)), and Docker/Kubernetes egress sidecars gain opt-in OTLP kernel drop counters and bounded NFLOG packet sampling ([#3094](https://github.com/opensandbox-group/OpenSandbox/pull/3094) [#3125](https://github.com/opensandbox-group/OpenSandbox/pull/3125))

## Server

- **Stateless HMAC-derived `execd` authentication on Kubernetes:** opt-in `[execd].auth_signing_key_file` (`server.execdAuth.existingSecret` in Helm, hot-reloaded on `mtime`/`inode` changes) injects one-way `sha256:<kid>:<nonce>:<verifier>` hashes into `BatchSandbox` (direct and pooled) and `AgentSandbox` workloads instead of plaintext credentials, recomputes `X-EXECD-ACCESS-TOKEN` on `GetEndpoint(44772)`, and rejects `use_server_proxy=true` on port `44772` with `400 INVALID_PARAMETER` ([#3080](https://github.com/opensandbox-group/OpenSandbox/pull/3080))
- **Async `grpc.aio` FastPath creates & shared `SandboxPool` informer:** `FastSandboxService.create_sandbox()` runs directly on the FastAPI event loop via `grpc.aio` instead of serializing behind the 32-worker `ThreadPoolExecutor` ([#3150](https://github.com/opensandbox-group/OpenSandbox/pull/3150)), and resolves `SandboxPool` mode, resource profile, and action handlers from the shared `K8sClient` informer instead of per-create `GetPool` RPCs (with `sandboxpools.sandbox.fast.io` read RBAC and a `403` `GetPool` fallback during rolling upgrades) ([#3120](https://github.com/opensandbox-group/OpenSandbox/pull/3120))
- **Image pull failure progress on `Pending` sandboxes:** `GET /v1/sandboxes/{id}` surfaces `status.reason = "IMAGE_PULL_FAILING"` and the pod/kubelet pull error in `status.message` while a `BatchSandbox` container or init container is in `ImagePullBackOff` or `ErrImagePull`, clearing once the image pulls ([#2967](https://github.com/opensandbox-group/OpenSandbox/pull/2967))
- **Egress kernel drop telemetry passthrough:** allowlists `OPENSANDBOX_EGRESS_DROP_TELEMETRY`, `OPENSANDBOX_EGRESS_DROP_LOG_RATE`, and `OPENSANDBOX_EGRESS_DROP_COUNTER_POLL` for Docker and Kubernetes egress sidecars ([#3125](https://github.com/opensandbox-group/OpenSandbox/pull/3125))
- **Refuse `BatchSandbox` pause on gVisor runtimes:** `pause_sandbox` checks the running Pod's `RuntimeClass` before patching `spec.pause` and rejects `runsc`/`runsc-*` handlers (as well as missing running Pods or unreadable `RuntimeClass`es) with `409 KUBERNETES::INVALID_STATE` instead of succeeding while losing files written under `runsc`'s `--overlay2=root:self` ([#3076](https://github.com/opensandbox-group/OpenSandbox/pull/3076))
- **`RootfsOnly` snapshot restore on `LegacySlot` pools:** dispatches `CreateRootfsSandbox` and relaxed CPU/memory override validation only on `ResourceAware` pools, falling back to `CreateSandbox` on `LegacySlot` pools instead of rejecting non-override restores with HTTP 400 ([#3097](https://github.com/opensandbox-group/OpenSandbox/pull/3097))
- **Smaller fixes:** `POST /sandboxes` stops waiting immediately with `409` instead of timing out at `504` when a Kubernetes sandbox enters `Stopping` or disappears during startup ([#3118](https://github.com/opensandbox-group/OpenSandbox/pull/3118)); Starlette-raised 404/405/400 framework errors now return the lifecycle spec's `ErrorResponse` (`code`/`message`) instead of `{"detail": ...}` ([#3117](https://github.com/opensandbox-group/OpenSandbox/pull/3117)); `BatchSandbox` templates mounting the same volume at multiple `mountPath`s (such as ConfigMap `subPath` entries) preserve all mounts instead of dropping every mount after the first ([#3130](https://github.com/opensandbox-group/OpenSandbox/pull/3130))

## SDKs

- **Cross-origin redirect stripping & log redaction for `X-EXECD-ACCESS-TOKEN`:** Python, JavaScript, and Kotlin SDKs now strip `X-EXECD-ACCESS-TOKEN` on cross-origin redirects (matching C# and Go; browser fetch requests carrying the token take the guarded fail-closed redirect path) ([#3101](https://github.com/opensandbox-group/OpenSandbox/pull/3101)), and JavaScript and Kotlin redact `X-EXECD-ACCESS-TOKEN` in debug logs ([#3080](https://github.com/opensandbox-group/OpenSandbox/pull/3080))
- **SDK README API surface updates:** all five sandbox SDK READMEs document `mode="rootfsOnly"` snapshot capture semantics ([#3051](https://github.com/opensandbox-group/OpenSandbox/pull/3051)), and the Python, JavaScript, and C# READMEs document foreground `exit_code`/`exitCode`, `SandboxRateLimitException.retry_after`, and `readyTimeoutSeconds`/`ReadyTimeoutSeconds` ([#3052](https://github.com/opensandbox-group/OpenSandbox/pull/3052))

### Python

- MCP `sandbox_renew` tool description and docs clarify that `timeout_seconds` sets expiration from `now` (`now + timeout_seconds`, which can shorten remaining lifetime) rather than adding to the current expiry ([#3026](https://github.com/opensandbox-group/OpenSandbox/pull/3026))

## Controller

- **Opt-in Pod and Job informer label selectors:** `--pod-label-selector` and `--job-label-selector` (`controller.podLabelSelector` and `controller.jobLabelSelector` in Helm, empty by default) bound informer cache memory in shared clusters with unrelated tenant workloads, while snapshot result collection falls back to direct API reads if commit Pods are filtered out ([#3158](https://github.com/opensandbox-group/OpenSandbox/pull/3158))
- **Image pull failure condition on `BatchSandbox`:** records `ImagePullBackOff` and `ErrImagePull` details across containers and init containers while a sandbox is `Pending` so the server can report `IMAGE_PULL_FAILING` ([#2967](https://github.com/opensandbox-group/OpenSandbox/pull/2967))
- **Least-privilege ClusterRole tightening:** removes unused `secrets` (`get`/`list`/`watch`) permissions and narrows `events` to `create`/`patch` on `opensandbox-manager-role` across controller RBAC manifests and the Helm chart ([#3122](https://github.com/opensandbox-group/OpenSandbox/pull/3122))

## Execd

- **HMAC verifier support & `/internal/init` hardening:** `EXECD_ACCESS_TOKEN` verifies `sha256:<kid>:<nonce>:<hex>` (and `sha256:<hex>`) one-way hashes via constant-time comparison and logs a deprecation warning when legacy plaintext tokens are used ([#3080](https://github.com/opensandbox-group/OpenSandbox/pull/3080)); opt-in `--init-auth` / `EXECD_INIT_AUTH` (default `false`) guards `POST /internal/init` with the active token, preserves same-`sandboxId` tokens when `accessTokenHash` is omitted, rolls back `RuntimeBinding` on 500 startup failures, and caps `/internal/init` request bodies at 1 MiB (`413`) ([#3103](https://github.com/opensandbox-group/OpenSandbox/pull/3103))
- **Streamlined core OTLP telemetry (12 instruments):** adds `execd.system.memory.limit_bytes`, merges foreground isolated runs into `execd.execution.duration{operation="run_isolated"}` with long-running buckets up to 1 hour, excludes `/metrics/watch` from HTTP duration, omits failed resource observations instead of reporting false zeros, and drops redundant filesystem duration, active-connection, disk I/O op-count, and isolated upper-dir series ([#3134](https://github.com/opensandbox-group/OpenSandbox/pull/3134))
- **Isolated sessions survive interrupted runs:** `session-gate` places the workload shell into its own process group (`setpgid(0, 0)`) before signaling readiness so run cancellation or timeout `SIGINT` signals the workload group instead of terminating `bubblewrap` and destroying the session ([#3089](https://github.com/opensandbox-group/OpenSandbox/pull/3089))
- **Unacknowledged Jupyter execution timeout:** starts a 5-second kernel acknowledgment deadline when an execute request is written to the WebSocket, emitting a terminal `KernelAcknowledgmentTimeout` error and releasing the session lock instead of leaving `POST /code` hung indefinitely ([#3083](https://github.com/opensandbox-group/OpenSandbox/pull/3083))
- **Windows `cmd.exe` quoting:** passes Windows shell commands via `SysProcAttr.CmdLine` (`cmd /S /C "<code>"`) so embedded quotes and quoted executable paths with spaces reach `cmd.exe` without spurious `\"` backslashes ([#3144](https://github.com/opensandbox-group/OpenSandbox/pull/3144))

## Networking

### egress

- **Additive Credential Vault bindings & audit logging (OSEP-0025):** overlapping bindings with disjoint static headers and substitution surfaces now compose in deterministic precedence order (exact host before wildcard, then binding name; exchange bindings evaluate against the unmutated client request within a shared deadline, failing closed on collisions or resolver errors), committed vault mutations emit sanitized `INFO` audit logs, and MITM `credential proxy:` events route informational lines to `INFO` with `subject` / `client_ip` context ([#3169](https://github.com/opensandbox-group/OpenSandbox/pull/3169))
- **Opt-in kernel drop telemetry for sidecars:** adds shared nftables drop-counter polling and bounded NFLOG group-3085 packet sampling (`OPENSANDBOX_EGRESS_DROP_TELEMETRY`, `OPENSANDBOX_EGRESS_DROP_LOG_RATE`, `OPENSANDBOX_EGRESS_DROP_COUNTER_POLL`), exporting `egress.blocked.packets`, `egress.blocked.samples`, and `egress.drop_telemetry.sampler_up` on Docker and Kubernetes sidecars without extending DNS leases; Fast Sandbox wiring follows separately ([#3094](https://github.com/opensandbox-group/OpenSandbox/pull/3094) [#3125](https://github.com/opensandbox-group/OpenSandbox/pull/3125))
- **Fast Sandbox hot-path & teardown performance:** deduplicates gateway DNS redirect applies and batches `O(1)` named-set MITM nftables updates into `ApplyDenyFirst` (collapsing steady-state `SET_BINDING` to a single `nft -f -` transaction) ([#3151](https://github.com/opensandbox-group/OpenSandbox/pull/3151)); eliminates `dir.Sync()` on read-only `Snapshot()` calls, non-IMA/EVM double `fsync`s, and duplicate owner reads/rewrites on Actions v2 while failing closed on unconfirmed owner writes ([#3152](https://github.com/opensandbox-group/OpenSandbox/pull/3152)); compiles port sets once during Classic `dropEstablished` teardown ([#3090](https://github.com/opensandbox-group/OpenSandbox/pull/3090)); and lowers the experimental Fast Sandbox `credential-bound` default `OPENSANDBOX_EGRESS_FSB_PROCESS_TLS_CAPACITY` from `131072` to `32768` based on ~160 KB per-connection memory measurements ([#3053](https://github.com/opensandbox-group/OpenSandbox/pull/3053))
- **Smaller fixes:** experimental sidecar `NewLiveStore` now admits `exchange` credentials in live-revision vaults ([#3079](https://github.com/opensandbox-group/OpenSandbox/pull/3079)), covered by a `--profile live` real-image CI suite ([#3102](https://github.com/opensandbox-group/OpenSandbox/pull/3102)); Fast Sandbox `credential-bound` mode checks latch onto session configuration so `resolveVaultAccess` fails closed (`400`) across child detach/restart transitions ([#3069](https://github.com/opensandbox-group/OpenSandbox/pull/3069)); Classic `/policy` rolls back the candidate policy file on nftables apply failure before logging so a stalled log sink cannot leave a rejected policy on disk ([#3108](https://github.com/opensandbox-group/OpenSandbox/pull/3108)); shared Zap rotating file logger reuses one writer per identical path so internal diagnostics stay in the active file after rotation (shared with ingress) ([#3126](https://github.com/opensandbox-group/OpenSandbox/pull/3126))

### ingress

- **Block `/internal/init` on `execd` port `44772`:** rejects requests targeting `/internal/init` (including normalized and percent-encoded path variants) on port `44772` with `403 Forbidden` across Header, URI, signed, and Fast Sandbox routing modes before endpoint resolution or wake-on-access ([#3111](https://github.com/opensandbox-group/OpenSandbox/pull/3111))
- **Streamlined OTLP metrics (14 instruments) & package boundaries:** adds `ingress.requests.active`, request `outcome` labels, and terminal `ingress.wake.duration`, fixes streaming completion, per-provider routing, and restore-permit parking accounting, and removes host resource gauges, duplicate counters, and detailed shadow count gauges ([#3132](https://github.com/opensandbox-group/OpenSandbox/pull/3132)); clarifies internal `connectivity`/`proxy` package boundaries ([#3129](https://github.com/opensandbox-group/OpenSandbox/pull/3129)) and tidies `go.mod`/`go.sum` ([#3071](https://github.com/opensandbox-group/OpenSandbox/pull/3071))
- **Full-duplex HTTP/1 proxying:** enables `ResponseController.EnableFullDuplex()` (requiring Go `1.26.11`) so early streaming responses from `execd` or isolated sessions no longer race unread/EOF request body reads and truncate mid-stream, while explicitly setting `Connection: close` when unread bodies remain ([#3087](https://github.com/opensandbox-group/OpenSandbox/pull/3087))
- **Evict failed FastPath routes after client cancellation:** bounds FastPath HTTP connection dials to 5 seconds (without capping streaming bodies) and conditionally invalidates cached routes when a dial fails or times out after client cancellation so deleted Fastlet Pod blackholes do not pin retries ([#3133](https://github.com/opensandbox-group/OpenSandbox/pull/3133))

## Fast Sandbox

- **Local `exec` `ActionHandler` support (`SandboxPool` CRD):** `SandboxPool` `spec.sandbox.actionHandlers` adds an `exec` variant (`command` argv template executed via `execve`, `timeoutSeconds`, and `maxRetries`, mutually exclusive with `targetHTTPPort`) with FastPath `sensitive_input` preservation while parked and one-shot completion persistence across Fastlet restarts ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#269](https://github.com/opensandbox-group/fast-sandbox/pull/269))
- **Single-image OCI `RootfsOnly` snapshots & default OCI `virtio-balloon` FPR:** `RootfsOnly` OCI snapshots embed their VM manifest and optional state files directly in the rootfs image config (`fsb-vm pack --rootfs-only`), cutting cold-boot device preparation by ~407 ms while retaining two-image read/delete compatibility ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#258](https://github.com/opensandbox-group/fast-sandbox/pull/258)); OCI template builds (`fsb-vm build`) now enable zero-target `virtio-balloon` free-page reporting and `/entropy` by default and record `freePageReporting` in `manifest.json` ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#252](https://github.com/opensandbox-group/fast-sandbox/pull/252))
- **Cold-boot & slot network hot-path optimizations:** delegates empty hybrid upper creation on `fsb-vm create` to `overlaybd-ublkd` (`createIfMissing: true`, `rwType: "hybrid"`, ~46 ms saved) ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#286](https://github.com/opensandbox-group/fast-sandbox/pull/286)) and pre-warms default baked guest `/32` routes and `FSB_GUEST_DNAT`/`SNAT` rules during slot `Prepare` (~40 ms saved per restore) ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#285](https://github.com/opensandbox-group/fast-sandbox/pull/285))
- **Cluster-wide `FAST_SANDBOX_NETWORK_CIDR` & per-registry `plainHTTP`:** controller validates and propagates `FAST_SANDBOX_NETWORK_CIDR` (`/8`–`/29`) to template builders and pool Fastlets to unlock >126 slots per Fastlet without CIDR drift ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#284](https://github.com/opensandbox-group/fast-sandbox/pull/284)); `fast-sandbox-registry` `registries.yaml` adds per-entry `plainHTTP: true` (allowing omitted `secretRef` for anonymous in-cluster HTTP registries across builder, Fastlet, and snapshot deletion, with `yaml.UnmarshalStrict` config validation) ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#281](https://github.com/opensandbox-group/fast-sandbox/pull/281) [fast-sandbox#283](https://github.com/opensandbox-group/fast-sandbox/pull/283))
- **Control-plane RBAC moved to `charts/fast-sandbox` & least-privilege tightening:** moves the 12 Fast Sandbox control-plane ServiceAccounts and RBAC objects out of `charts/base` into `charts/fast-sandbox` (`rbac.create`, default `true`) so default umbrella installs (`fast-sandbox.enabled=false`) render zero Fast Sandbox RBAC ([#3100](https://github.com/opensandbox-group/OpenSandbox/pull/3100)); trims unused `nodes`, `runtimeclasses`, `secrets` (`fast-sandbox-fastpath`), and excess `configmaps`/`secrets` `delete` verbs across chart and upstream manifests, and scopes upstream kustomize leader-election `leases` to `fast-sandbox-system` ([#3122](https://github.com/opensandbox-group/OpenSandbox/pull/3122) [#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#270](https://github.com/opensandbox-group/fast-sandbox/pull/270) [fast-sandbox#271](https://github.com/opensandbox-group/fast-sandbox/pull/271) [fast-sandbox#278](https://github.com/opensandbox-group/fast-sandbox/pull/278) [fast-sandbox#288](https://github.com/opensandbox-group/fast-sandbox/pull/288))
- **Fastlet memory admission & PSI resilience:** Fastlet `ResourceAware` memory admission excludes reclaimable unmapped page cache from `memory.current` so checkpoint/restore I/O cache no longer stalls idle Fastlets above the high watermark ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#263](https://github.com/opensandbox-group/fast-sandbox/pull/263)), and ignores `EOPNOTSUPP` on cgroup v2 `memory.pressure` when hosts run without `psi=1` ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#280](https://github.com/opensandbox-group/fast-sandbox/pull/280))
- **Template guest `/etc/hosts` & baked MITM CA readiness gate:** template builds append `127.0.0.1 sandbox` to `/etc/hosts` so guest tools like `sudo` do not stall on hostname lookup ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#266](https://github.com/opensandbox-group/fast-sandbox/pull/266)), export `MITM_CA_WATCH_INTERVAL=0` for baked MITM CAs, and verify trust-store installation before emitting `SANDBOX_READY` ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#279](https://github.com/opensandbox-group/fast-sandbox/pull/279)); upstream README clarifies control-plane architectural boundaries ([#3165](https://github.com/opensandbox-group/OpenSandbox/pull/3165) [fast-sandbox#268](https://github.com/opensandbox-group/fast-sandbox/pull/268))

## Upgrade & Compatibility

- **`BatchSandbox` pause refused on gVisor runtimes:** `POST /sandboxes/{id}/pause` on a `BatchSandbox` backed by a `runsc`/`runsc-*` `RuntimeClass` (or without a running Pod or readable `RuntimeClass`) now returns `409 KUBERNETES::INVALID_STATE` instead of succeeding while losing pre-pause filesystem writes ([#3076](https://github.com/opensandbox-group/OpenSandbox/pull/3076))
- **Server HTTP error envelope & deleted-during-create status:** Starlette-raised 404/405/400 framework errors now return `ErrorResponse` (`{"code":"GENERAL::UNKNOWN_ERROR","message":...}`) instead of `{"detail":...}` ([#3117](https://github.com/opensandbox-group/OpenSandbox/pull/3117)); `POST /sandboxes` returns `409` immediately instead of waiting for `504` when a Kubernetes sandbox is deleted during startup ([#3118](https://github.com/opensandbox-group/OpenSandbox/pull/3118)); Fast Sandbox creates targeting a missing pool alongside an unsupported request field now return `404 FSB_POOL_NOT_FOUND` instead of `400` ([#3120](https://github.com/opensandbox-group/OpenSandbox/pull/3120))
- **Server RBAC for `SandboxPool` informer:** `manifests/charts/server` adds read-only `get`/`list`/`watch` on `sandboxpools.sandbox.fast.io`; rolling server upgrades ahead of RBAC fall back automatically to `FastPath.GetPool` with a warning until RBAC converges ([#3120](https://github.com/opensandbox-group/OpenSandbox/pull/3120))
- **Helm chart split for Fast Sandbox RBAC:** `charts/base` no longer renders Fast Sandbox control-plane ServiceAccounts or RBAC; operators installing `base` and `fast-sandbox` as standalone Helm releases rather than the umbrella chart must upgrade both together ([#3100](https://github.com/opensandbox-group/OpenSandbox/pull/3100))
