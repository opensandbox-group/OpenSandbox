Third release candidate on the `1.3.0` feature line, cut from `release-1.3.0-rc.2` (2026-11-19). Baseline for every section is `release-1.3.0-rc.2`; rc users on that tag should upgrade. rc releases publish images but hold packages — SDK/CLI artifacts ship at the `1.3.0` stable bump.

## Highlights

- **Egress upstream proxy forward mode (OSEP-0030):** opt-in `[egress] mode = "forward"` relays all outbound IPv4 TCP traffic via `CONNECT` with `Proxy-Authorization` and sandbox/namespace/tenant identity headers on Docker and Kubernetes non-pooled runtimes — no local TLS interception, fail-closed on UDP/ICMP/IPv6/link-local ([#3002](https://github.com/opensandbox-group/OpenSandbox/pull/3002) [#3030](https://github.com/opensandbox-group/OpenSandbox/pull/3030))
- **RootfsOnly resource overrides & faster Fast Sandbox cold boots:** `POST /sandboxes` accepts per-create CPU/memory overrides on Firecracker RootfsOnly restores ([#2933](https://github.com/opensandbox-group/OpenSandbox/pull/2933) [fast-sandbox#231](https://github.com/opensandbox-group/fast-sandbox/pull/231)), paired with Firecracker hot-path caching and a baked-CA fast path that drops the 15-second cold-boot wait ([#2957](https://github.com/opensandbox-group/OpenSandbox/pull/2957) [#2989](https://github.com/opensandbox-group/OpenSandbox/pull/2989) [fast-sandbox#239](https://github.com/opensandbox-group/fast-sandbox/pull/239) [fast-sandbox#243](https://github.com/opensandbox-group/fast-sandbox/pull/243) [fast-sandbox#244](https://github.com/opensandbox-group/fast-sandbox/pull/244))
- **Optional FastPath caller auth (OSEP-0032) & authenticated Fastlet key fetch:** server and gateway can authenticate FastPath RPCs over TLS with Kubernetes ServiceAccount tokens (default-off `callerAuth.enabled=false`), and Fastlet OIDC/JWKS discovery drops the anonymous `system:unauthenticated` binding ([#2989](https://github.com/opensandbox-group/OpenSandbox/pull/2989) [#2940](https://github.com/opensandbox-group/OpenSandbox/pull/2940) [fast-sandbox#232](https://github.com/opensandbox-group/fast-sandbox/pull/232) [fast-sandbox#235](https://github.com/opensandbox-group/fast-sandbox/pull/235) [fast-sandbox#237](https://github.com/opensandbox-group/fast-sandbox/pull/237) [fast-sandbox#245](https://github.com/opensandbox-group/fast-sandbox/pull/245))

## Server

- **Egress forward mode (OSEP-0030):** `[egress] mode = "forward"` attaches egress unconditionally on Docker bridge and Kubernetes non-pooled (`BatchSandbox` template / `AgentSandbox`) runtimes (with an `egress-init` default-drop bootstrap fence on Kubernetes), drops `NET_ADMIN`/`NET_RAW`, injects identity headers, and rejects incompatible features (`networkPolicy`, `credentialProxy`, gVisor, pooled `poolRef`, Windows, Fast Sandbox) with HTTP 400 ([#3002](https://github.com/opensandbox-group/OpenSandbox/pull/3002) [#3030](https://github.com/opensandbox-group/OpenSandbox/pull/3030))
- **RootfsOnly resource overrides (OSEP-0028):** `POST /sandboxes` accepts partial or full `resourceLimits` with `snapshotId` on Firecracker ResourceAware pools (omitted dimensions inherit the captured quota; returns 503 if the controller lacks the RPC) ([#2933](https://github.com/opensandbox-group/OpenSandbox/pull/2933))
- **Dedicated Pod metadata sync:** opt-in `[kubernetes] metadata_sync_pods = true` syncs accepted metadata PATCH changes (including `null` removals) to dedicated Pods and persists recreation overlays in `sandbox.opensandbox.io/pod-label-overrides` ([#2869](https://github.com/opensandbox-group/OpenSandbox/pull/2869)), fenced with `resourceVersion` and uncached re-reads so concurrent PATCHes do not clobber each other ([#2992](https://github.com/opensandbox-group/OpenSandbox/pull/2992))
- **Pinned `execd` isolation config:** opt-in `runtime.execd_isolation_config` sets `EXECD_ISOLATION_CONFIG` with precedence over caller env values across Docker, Kubernetes Pods, and pool tasks ([#3021](https://github.com/opensandbox-group/OpenSandbox/pull/3021))
- **Capability drops preserved:** BatchSandbox template `securityContext.capabilities.drop` entries are merged instead of overwritten when network policy is enabled; templates dropping `SYS_ADMIN` reject execd isolation with `400 INVALID_PARAMETER` ([#3037](https://github.com/opensandbox-group/OpenSandbox/pull/3037))
- **Full snapshot recovery scan:** recovery now pages through all unfinished `Creating`/`Deleting` snapshots via a `(created_at, id)` keyset cursor instead of stopping after the first 200 rows ([#3027](https://github.com/opensandbox-group/OpenSandbox/pull/3027))
- **Richer failure messages:** `GET /v1/sandboxes/{id}` `status.message` preserves the failing container's detail from `BatchSandbox`'s `PodFailed` condition ([#2966](https://github.com/opensandbox-group/OpenSandbox/pull/2966))

## SDKs

- **Incomplete foreground stream detection:** all five SDKs (Python sync/async, JavaScript, Kotlin, C#, Go) now fail foreground commands whose SSE stream hits EOF without an `execution_complete` or `error` event instead of returning a partial result; `osb command run` exits with code 1 ([#2914](https://github.com/opensandbox-group/OpenSandbox/pull/2914))
- **RootfsOnly overrides & log-cursor docs:** all five sandbox SDKs support `resourceLimits` on RootfsOnly restores ([#2933](https://github.com/opensandbox-group/OpenSandbox/pull/2933)) and document byte-offset cursor semantics and the 16 MiB read cap for `GET /command/{id}/logs` ([#3033](https://github.com/opensandbox-group/OpenSandbox/pull/3033))

### Python

- Built-in health probes (`ping()`, `is_healthy()`, pool warmup) cap each request phase at `min(request_timeout, 5s)` so a stalled first connection cannot exhaust the readiness budget ([#3014](https://github.com/opensandbox-group/OpenSandbox/pull/3014))
- Propagated adapter failures (such as 404 `FILE_NOT_FOUND`) now log at `DEBUG` instead of `ERROR` ([#2996](https://github.com/opensandbox-group/OpenSandbox/pull/2996))

### JavaScript

- Code-interpreter `codes.runStream()` and `codes.run()` cancel and release the response reader in `try/finally` on early exit or handler rejection ([#2179](https://github.com/opensandbox-group/OpenSandbox/pull/2179))

### Kotlin

- SSE streams (`commands.run`, code interpreter, isolated sessions) enforce a `max(requestTimeout, 30s)` read timeout, raising `SandboxTimeoutException` instead of hanging forever ([#2847](https://github.com/opensandbox-group/OpenSandbox/pull/2847))
- Execution handler exceptions in SSE loops now abort stream processing and surface as `SandboxException` instead of being swallowed ([#2994](https://github.com/opensandbox-group/OpenSandbox/pull/2994))

### Go

- Explicit `OPEN-SANDBOX-API-KEY` and `X-EXECD-ACCESS-TOKEN` entries in `ConnectionConfig.Headers` now take case-insensitive precedence over configured defaults across request builders, raw execd calls, and create telemetry ([#2764](https://github.com/opensandbox-group/OpenSandbox/pull/2764))

## Controller

- **Indexed pooled Pod lookup:** pooled Pod events resolve target BatchSandboxes via an informer reverse index (`namespace/pool/pod`) instead of scanning every BatchSandbox in the pool ([#3038](https://github.com/opensandbox-group/OpenSandbox/pull/3038))
- **Finished pool pod reaping & status:** `Failed`/`Succeeded` idle pods are excluded from `Pool` capacity status ([#2929](https://github.com/opensandbox-group/OpenSandbox/pull/2929)) and reaped in `scalePool` without consuming scale-up/scale-down budgets ([#2658](https://github.com/opensandbox-group/OpenSandbox/pull/2658)), preventing evicted buffers from stalling refills
- **Stale scheduler fencing:** task schedulers validate Pod name, IP, UID, and non-terminating state before status reads or dispatch, failing unfinished tasks and releasing bindings locally so reused Pod IPs or terminating Pods are never contacted ([#3015](https://github.com/opensandbox-group/OpenSandbox/pull/3015) [#3016](https://github.com/opensandbox-group/OpenSandbox/pull/3016))
- **Pool & task lifecycle fixes:** `SetReleased` re-reads via an uncached API reader with optimistic locking to avoid forbidden finalizer re-additions ([#2950](https://github.com/opensandbox-group/OpenSandbox/pull/2950)); Pool allocations isolate by controller UID across same-name recreation ([#2973](https://github.com/opensandbox-group/OpenSandbox/pull/2973)); pool scaling excludes missing allocated pods so `BufferMax` is not exceeded ([#2991](https://github.com/opensandbox-group/OpenSandbox/pull/2991)); task pod releases adopt the updated `resourceVersion` and skip no-ops to avoid self-inflicted 409 status conflicts ([#2985](https://github.com/opensandbox-group/OpenSandbox/pull/2985))

## Execd

- **Process QoS launch policy (OSEP-0031 Phase 1):** opt-in `[qos]` in `EXECD_ISOLATION_CONFIG` configures best-effort `RLIMIT_NICE`, nice/`SCHED_IDLE` scheduling, initial `oom_score_adj`, and a `high` tier for managed ENTRYPOINTs; bumps internal launcher policy to v2 ([#2959](https://github.com/opensandbox-group/OpenSandbox/pull/2959))
- **OTLP gRPC metrics export:** `OTEL_EXPORTER_OTLP_METRICS_PROTOCOL=grpc` (node fallback `:4317`) is now supported alongside HTTP/protobuf across execd, egress, ingress, and node-agent ([#2999](https://github.com/opensandbox-group/OpenSandbox/pull/2999))
- **Faster MITM CA bootstrap & file search:** bootstrap trusts immediately on `MITM_CA_STABILIZE_WINDOW=0`, caches installed CA fingerprints on the rootfs to skip redundant trust-store rebuilds, and disables the watcher when `MITM_CA_WATCH_INTERVAL<=0` ([#2957](https://github.com/opensandbox-group/OpenSandbox/pull/2957)); file search filters filenames via `WalkDir` before `Lstat` ([#3000](https://github.com/opensandbox-group/OpenSandbox/pull/3000)), and isolated `MergedView.Search` merges upper-layer passes and skips redundant lower scans ([#3013](https://github.com/opensandbox-group/OpenSandbox/pull/3013))
- **Bounded log reads & multi-range downloads:** `GET /command/{id}/logs` caps reads at 16 MiB and corrects cursor docs to byte offsets ([#3033](https://github.com/opensandbox-group/OpenSandbox/pull/3033)); multi-range file downloads fall back to HTTP 200 with the full file instead of returning only the first slice ([#3034](https://github.com/opensandbox-group/OpenSandbox/pull/3034))
- **Smaller fixes:** per-user filesystem endpoints treat missing `/etc/passwd` or `/etc/group` like unknown UIDs instead of 503 ([#2949](https://github.com/opensandbox-group/OpenSandbox/pull/2949)); Jupyter `POST /code` finalization tracks in-flight output sends so slow consumers don't lose tail output ([#2979](https://github.com/opensandbox-group/OpenSandbox/pull/2979)); transient NSS/JDK MITM CA import failures retry up to three times per generation ([#2987](https://github.com/opensandbox-group/OpenSandbox/pull/2987)); disk usage gauges use `f_frsize` ([#2982](https://github.com/opensandbox-group/OpenSandbox/pull/2982)) and cgroup disk IO skips stacked `dm*`/`loop*`/`md*` devices ([#2983](https://github.com/opensandbox-group/OpenSandbox/pull/2983))

## Networking

### egress

- **Upstream proxy forward mode (OSEP-0030):** `OPENSANDBOX_EGRESS_MODE=forward` relays redirected IPv4 TCP verbatim via `CONNECT` with `Proxy-Authorization` and identity headers (`SO_MARK 0x4`), drops UDP/ICMP/IPv6/link-local fail-closed, gates `/healthz` on gateway reachability, disables `/policy` (409), and supports `egress-init` fencing on Kubernetes ([#3002](https://github.com/opensandbox-group/OpenSandbox/pull/3002) [#3030](https://github.com/opensandbox-group/OpenSandbox/pull/3030))
- **Structured DNS policy logs:** policy-evaluated DNS logs add `dns.policy.decision`, `dns.stage`, and `dns.response_code` (plus `target.host` on denials) ([#3036](https://github.com/opensandbox-group/OpenSandbox/pull/3036))
- **Fast Sandbox exchange vault readiness:** credential-bound exchange vaults now resolve from admitted decision snapshots in live H1/H2 hooks instead of failing readiness at 503 ([#2930](https://github.com/opensandbox-group/OpenSandbox/pull/2930))
- **Classic `dns+nft` lease & failure semantics:** DNS leases are tracked per domain so shorter TTLs don't truncate shared-IP grants, still-permitted grants survive default-deny policy replacements, and unacknowledged applies pause new grants ([#2998](https://github.com/opensandbox-group/OpenSandbox/pull/2998)); failed nftables rule installs ([#2952](https://github.com/opensandbox-group/OpenSandbox/pull/2952)) and default-deny tracking-capacity overflow ([#2961](https://github.com/opensandbox-group/OpenSandbox/pull/2961)) now return address-free `SERVFAIL` instead of `NOERROR`
- **Smaller fixes:** Fast Sandbox INPUT rules specify `meta l4proto tcp` before `ct original proto-dst` for nftables 1.0.6 compatibility ([#2958](https://github.com/opensandbox-group/OpenSandbox/pull/2958)); HTTP/2 and HTTP/3 `cookie` crumbs are joined with `"; "` before exchange resolution ([#2980](https://github.com/opensandbox-group/OpenSandbox/pull/2980)); resolved DNS IP extraction avoids text round trips ([#3029](https://github.com/opensandbox-group/OpenSandbox/pull/3029)); Fast Sandbox snapshot-mutation test awaits injected `Prepare` rejection before authority loss ([#3028](https://github.com/opensandbox-group/OpenSandbox/pull/3028))

### ingress

- **Single-namespace Fast Sandbox wildcard routes:** `--fast-sandbox-namespace` (`gateway.fastSandboxNamespace` in Helm) enables unsigned `<sandbox-id>-<port>.<gateway-domain>` routing scoped to one namespace via Host ([#2955](https://github.com/opensandbox-group/OpenSandbox/pull/2955)) or `OpenSandbox-Ingress-To` ([#2981](https://github.com/opensandbox-group/OpenSandbox/pull/2981)), matching `fsb-` labels case-insensitively ([#2988](https://github.com/opensandbox-group/OpenSandbox/pull/2988))
- **Upstream HTTP connection pool tuning:** adds `--http-max-idle-conns`, `--http-max-idle-conns-per-host`, `--http-idle-conn-timeout`, and `gateway.httpConnectionPool` Helm values (defaults unchanged at `100 / 2 / 90s`) ([#3001](https://github.com/opensandbox-group/OpenSandbox/pull/3001))

## Fast Sandbox

- **RootfsOnly CPU/memory overrides (FSEP-0005):** Firecracker ResourceAware pools accept partial or full per-create CPU/memory limits via a dedicated FastPath RPC and preserve host CPU quota separately from guest vCPU count across managed resume ([#2933](https://github.com/opensandbox-group/OpenSandbox/pull/2933) [fast-sandbox#231](https://github.com/opensandbox-group/fast-sandbox/pull/231))
- **Optional FastPath caller authentication (OSEP-0032):** opt-in (`fastpath.callerAuth.enabled` / `fastpath_auth_enabled`, default `false`) enforces verified TLS and audience-bound Kubernetes ServiceAccount tokens across server, ingress gateway, and FastPath (native gRPC and gRPC-Web), reusing `opensandbox-server` and `opensandbox-ingress-gateway` ServiceAccounts ([#2989](https://github.com/opensandbox-group/OpenSandbox/pull/2989) [fast-sandbox#245](https://github.com/opensandbox-group/fast-sandbox/pull/245))
- **Authenticated Fastlet OIDC/JWKS key fetch (FSEP-0003):** Fastlets fetch discovery/JWKS using per-namespace `fast-sandbox-fastlet` projected tokens, replacing the `system:unauthenticated` ClusterRoleBinding with an authenticated `system:serviceaccounts` grant in the base chart (unblocking ACK marketplace admission), preserving `imagePullSecrets`, dropping kubeadm-breaking strict origin pinning, and honoring `KUBERNETES_SERVICE_PORT` ([#2940](https://github.com/opensandbox-group/OpenSandbox/pull/2940) [#2951](https://github.com/opensandbox-group/OpenSandbox/pull/2951) [fast-sandbox#232](https://github.com/opensandbox-group/fast-sandbox/pull/232) [fast-sandbox#235](https://github.com/opensandbox-group/fast-sandbox/pull/235) [fast-sandbox#237](https://github.com/opensandbox-group/fast-sandbox/pull/237))
- **Firecracker cold-boot & snapshot hot-path optimizations:** caches pinned kernels, VMM versions, and materialized OverlayBD snapfiles ([fast-sandbox#239](https://github.com/opensandbox-group/fast-sandbox/pull/239)); eliminates redundant native/S3 multi-GiB SHA-256 passes, uses Linux `FICLONE` ioctl, and commits published templates to the node-local cache ([fast-sandbox#244](https://github.com/opensandbox-group/fast-sandbox/pull/244)); exports `MITM_CA_STABILIZE_WINDOW=0` for baked MITM CAs ([fast-sandbox#243](https://github.com/opensandbox-group/fast-sandbox/pull/243)); and adds OCI create stage timing logs ([#2951](https://github.com/opensandbox-group/OpenSandbox/pull/2951) [#2933](https://github.com/opensandbox-group/OpenSandbox/pull/2933) [#2989](https://github.com/opensandbox-group/OpenSandbox/pull/2989) [fast-sandbox#238](https://github.com/opensandbox-group/fast-sandbox/pull/238))
- **Advisory registry-config revision:** `fast-sandbox-agent-registry` treats `revision` as advisory instead of failing on content-digest mismatch ([#2989](https://github.com/opensandbox-group/OpenSandbox/pull/2989) [fast-sandbox#242](https://github.com/opensandbox-group/fast-sandbox/pull/242))

- **Fast Sandbox coordinated upgrades:** upgrade `fsb-*` images before server for RootfsOnly overrides (older controllers return 503) ([#2933](https://github.com/opensandbox-group/OpenSandbox/pull/2933)); upgrade the base chart and `fsb-*` images together for authenticated Fastlet discovery (no anonymous fallback) ([#2940](https://github.com/opensandbox-group/OpenSandbox/pull/2940) [fast-sandbox#232](https://github.com/opensandbox-group/fast-sandbox/pull/232)); FastPath caller auth defaults to `false` — enabling it requires cert-manager, CA distribution, and rolling FastPath, server, and gateway together ([#2989](https://github.com/opensandbox-group/OpenSandbox/pull/2989) [#3046](https://github.com/opensandbox-group/OpenSandbox/pull/3046))
- **Egress lockstep & Classic `dns+nft` changes:** upgrade egress and its bundled mitmproxy addon together in credential-bound mode ([#2930](https://github.com/opensandbox-group/OpenSandbox/pull/2930)); failed nftables installs and default-deny tracking overflow now return `SERVFAIL` instead of `NOERROR` ([#2952](https://github.com/opensandbox-group/OpenSandbox/pull/2952) [#2961](https://github.com/opensandbox-group/OpenSandbox/pull/2961)); default-deny policy replacements now preserve still-permitted DNS grants instead of flushing them ([#2998](https://github.com/opensandbox-group/OpenSandbox/pull/2998))
