# OpenSandbox 1.1.0-rc.1

Release candidate for the 1.1.0 line and the first end-to-end exercise of the
unified umbrella release pipeline (OSEP-0016). It carries the version bump to
`1.1.0-rc.1` across charts, image references, and SDK package versions; no
functional changes are included. Please test the release mechanics — staging
image builds, BOM assembly, and held package fan-out — and report issues.

## Highlights

- First umbrella release candidate on the 1.1.0 line
- Platform version aligned to `1.1.0-rc.1` (charts, images, SDKs)

## Misc

- release: bump platform version to 1.1.0-rc.1 (#1896)

## Upgrade & Compatibility

- Images: `opensandbox/<component>:release-1.1.0-rc.1` (all three registries)
- Packages: server / CLI / SDKs all at `1.1.0-rc.1` (held, not published — rc)
- Charts: render from this tag (`helm template ./manifests/charts/opensandbox`)
- Kubernetes: supported range v1.24 – v1.34
- Skew: server ↔ CLI/SDK same line supported; ±1 minor warns

## Artifacts

- BOM: [docs/releases/1.1.0-rc.1.yaml](./1.1.0-rc.1.yaml)
- Images: `opensandbox/<component>:release-1.1.0-rc.1` (Docker Hub / GHCR / ACR)

## Installation

```bash
# Platform (Kubernetes) — render the chart at this tag and apply
git clone https://github.com/opensandbox-group/OpenSandbox
git checkout release-1.1.0-rc.1
helm template ./manifests/charts/opensandbox | kubectl apply -f -
```

Verify what you installed against the BOM: see
[Release Verification](/community/release-verification).
